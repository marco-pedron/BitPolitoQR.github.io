02 · The Lab

Where BitPolito builds

The Lab is BitPolito's research and development unit. Students turn Bitcoin specifications into working code — reference implementations, research tooling and teaching prototypes — across four tracks: cryptography, AI/ML, mining and off-chain protocols. Every project is public on GitHub.

TRACK 01

Cryptography & self-custody

Readable, tested implementations of the signature and privacy schemes Bitcoin relies on — written to be studied, run and taught, plus hardware to keep keys off the internet.

  • Schnorr signatures and key aggregation (BIP 340, MuSig1 / MuSig2)
  • Receiver privacy with Silent Payments (BIP 352)
  • Verification against official BIP test vectors
  • Air-gapped, stateless signing devices with QR-based PSBT exchange

Projects

Silent PaymentsBIP 352 · educational PoC

Derives silent-payment outputs, scans synthetic transactions, verifies spending signatures and searches vanity addresses with a native Rust engine.

Guided sender/receiver walkthrough and 28 pinned reference-case groups. Nothing is broadcast; testnet by default.

  • React
  • Flask
  • Rust
Live demo Repo

Schnorr & MuSigBIP 340 · Python library

Key generation, Schnorr signing and verification, and MuSig1/MuSig2 key aggregation from the command line.

Signing follows the BIP 340 reference implementation and is tested against its official vectors; a Jupyter notebook walks through the maths.

  • Python
  • Jupyter
  • secp256k1
Repo

SeedSigner by BitPolitoAir-gapped signing device

A BitPolito-themed SeedSigner OS image for Raspberry Pi Zero: a verifiably air-gapped, stateless signer built from parts that usually cost under $50.

Transactions move over QR codes only; supports single-sig and multisig setups.

  • Python
  • Raspberry Pi
  • PSBT

TRACK 02

AI / ML, local-first

AI for Bitcoin education and agents that runs on your own machine: open-weight models, no API keys, and no documents leaving the device.

  • Retrieval-augmented tutoring over real course material
  • Hybrid search: dense embeddings + BM25 + reranking
  • On-device inference sized for student laptops
  • AI agents that hold and move value self-custodially

Projects

BitPolito AcademyOpen-source, local-first AI tutor

Upload slides, PDFs or textbooks and study them through eight actions:

  • explain
  • summarize
  • retrieve
  • open_questions
  • quiz
  • oral
  • derive
  • compare

Retrieval combines QVAC dense search (GTE-Large FP16) with BM25, cross-encoder reranking and MMR diversity; Qwen3-4B optionally writes the answers, and a semantic cache skips repeated queries. Needs about 8 GB of RAM, or ~670 MB in retrieval-only mode.

  • QVAC
  • Qwen3-4B
  • Next.js
  • Python
  • Docker

TRACK 03

Mining & on-chain data

From proof-of-work fundamentals to pool decentralization: we simulate, measure and teach how blocks get made.

  • Teaching block construction and proof of work hands-on
  • Measuring mining-pool distribution from on-chain data
  • Watching coinbase data for Stratum V2 signalling
  • Running our own signet miner for layer-2 testing

Projects

Mining GameBitcoin block-mining simulator

Pick transactions from a mempool, maximize fees and find a valid nonce. Hard mode has you build a Bitcoin-style block header and grind it with double SHA-256.

Solo or multiplayer rooms for up to 30 players — built for classrooms, workshops and events, with guides in English and Italian.

  • React
  • Vite
  • Node.js
  • SHA-256d
Play now Repo

Bitcoin Data Analysisbitdata · Python toolkit

Pluggable data providers — Bitcoin Core RPC, mempool.space, Blockstream, QuickNode — with ready-made analyses: mining-pool distribution, transactions per block and Taproot usage.

Includes a coinbase monitor that scans new blocks for a target string such as “Stratum v2” and alerts a Telegram channel, plus a Streamlit dashboard with on-chain and Lightning pages.

  • Python
  • Streamlit
  • Poetry
  • Docker
Repo

TRACK 04

Off-chain protocols

Scaling Bitcoin without giving up self-custody: Lightning, client-side-validated assets with RGB, and the test infrastructure to break things safely.

  • Lightning nodes and Lightning Network data
  • RGB: assets issued and verified with client-side validation
  • Private signet testbeds for layer-2 software
  • Self-custodial digital-dollar apps settled on Bitcoin

Projects

Bitcoin Testing ToolsCustom signet sandbox

A Docker framework for running our own signet: a mining node, follower nodes and a Core Lightning node, with an Electrum server and a faucet exposed as Tor hidden services.

A shared playground to test Lightning and other layer-2 applications without touching mainnet.

  • Bitcoin Core
  • Core Lightning
